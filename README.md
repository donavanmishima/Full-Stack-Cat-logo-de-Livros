# Projeto Full-Stack Catálogo de Livros

Desenvolvido por Donavan Mishima, André Nonaka e Vinicius Hudson, esse projeto é uma atividade proposta pelo
professor Querino na disciplina de Desenvolvimento Web III, utilizando Node Express e React.

# O que o projeto faz?

É um sistema web front-end com back-end, onde voce consegue adicionar, ler, alterar e excluir (todos os métodos CRUD)
livros de sua preferencia, criando uma pequena biblioteca.
Você pode adicionar seus livros com algumas informações. Esse projeto é uma aplicação prática de como colocar uma 
API (que nós mesmo desenvolvemos) em um sistema front-end com REACT.

# Como rodar?

1 - Baixe as pastas "api-catalogo-livros" e "front-end catalogo de livros".
2 - Abra o VsCode e seu MongoCompass, crie uma conexão com localhost:27017 no Mongo.
3 - Abra cada pasta em uma janela diferente do vscode, ou seja, uma Tela para a api, e outra pro Front-end.
4 - Dê um npm install em cada pasta, na pasta "api-catalogo-livros" dê um npm install e dps npm install cors, para baixar
todos os pacotes necessários. Na pasta front-end dê apenas um npm install.

5 - Execute a pasta da api, dando um comando: node api.js, e aguarde a mensagem de conexão sucesso no Mongo.

6 - Dê um comando: npm run dev na pasta front-end, e entre no localhost que ele gerar;

7 - Aproveite e teste o projeto!
